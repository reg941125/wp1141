# 方塊堆疊益智遊戲

一個使用React製作的經典方塊堆疊益智遊戲（類似俄羅斯方塊）。
有音樂跟音效，記得開聲音！！！

## 功能特色

- 🎮 經典的方塊堆疊遊戲玩法
- 🎨 美觀的UI設計與動畫效果
- 🌄 好聽的背景音樂及音效
- 📊 完整的計分和等級系統
- 🔄 HOLD功能（暫存方塊）
- 👁️ 預覽下一個方塊
- 👻 鬼影方塊顯示落點
- ⌨️ 完整的鍵盤控制

## 遊戲控制

- **← →** : 左右移動方塊
- **↓** : 快速下降
- **↑** : 旋轉方塊
- **Space** : 瞬間下降到底部
- **Shift** : 暫存當前方塊
- **ESC** : 暫停/繼續遊戲

## 如何開始

1. 安裝依賴：
```bash
npm install
```

2. 啟動開發服務器：
```bash
npm start
```

3. 在瀏覽器中打開 http://localhost:3000

4. 點擊"START"開始遊戲！

## 遊戲規則

- 移動和旋轉下落的方塊，填滿整行來消除
- 消除的行數越多，分數越高
- 隨著等級提升，方塊下降速度會加快
- 使用HOLD功能可以暫存當前方塊，但每放置一個方塊只能使用一次
- 當方塊堆疊到頂部時遊戲結束

## 技術特色

- 使用React Hooks進行狀態管理
- 模組化的組件設計
- 響應式UI設計
- 流暢的動畫效果
- 完整的遊戲邏輯實現
- 音效管理系統
- 消除行特效動畫

## 音頻功能

遊戲支援背景音樂和音效：

### 音頻文件位置
將音頻文件放在 `public/audio/` 資料夾中：

- `background.mp3` - 背景音樂
- `line_clear.mp3` - 消除行音效
- `rotate.mp3` - 旋轉音效
- `move.mp3` - 移動音效
- `level_up.mp3` - 等級提升音效

### 音頻設置
- 音量控制
- 靜音功能
- 音效測試
- 自動循環播放
