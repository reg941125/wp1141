# 🗺️ 位置選擇功能 - 新增廁所改進

## 🎯 功能概述

為 NTU 廁所地圖應用程式新增了更直觀的位置選擇方式，讓用戶可以選擇在地圖上點選位置或手動輸入地址來新增廁所。

## ✨ 新功能特色

### 1. **雙重選擇方式**
- **📍 地圖上選擇位置**：直接在地圖上點擊選擇廁所位置
- **✏️ 手動輸入地址**：傳統的文字輸入方式

### 2. **直觀的用戶介面**
- **標籤頁設計**：清楚區分兩種選擇方式
- **即時反饋**：選擇位置後立即顯示座標資訊
- **視覺提示**：地圖上顯示選擇的位置標記

### 3. **智能驗證**
- **地圖模式**：必須點擊地圖選擇位置
- **輸入模式**：必須填寫完整地址
- **動態按鈕**：根據選擇方式啟用/禁用提交按鈕


#### 2. **地圖位置選擇**
```tsx
const handleLocationSelect = (location: { lat: number; lng: number }) => {
  setSelectedLocation(location);
  setSelectedAddress(`緯度: ${location.lat.toFixed(6)}, 經度: ${location.lng.toFixed(6)}`);
};
```

#### 3. **智能表單驗證**
```tsx

```

## 📱 用戶體驗流程

### 地圖選擇模式
1. **選擇標籤**：點擊「地圖上選擇位置」
2. **查看地圖**：顯示互動式 Google Maps
3. **點擊位置**：在地圖上點擊選擇廁所位置
4. **確認選擇**：顯示選擇的座標資訊
5. **填寫其他資訊**：廁所名稱、描述、標籤等
6. **提交**：完成新增

### 手動輸入模式
1. **選擇標籤**：點擊「手動輸入地址」
2. **輸入地址**：在文字框中輸入完整地址
3. **填寫其他資訊**：廁所名稱、描述、標籤等
4. **提交**：系統自動轉換地址為座標

## 🔄 資料流程

### 1. **地圖選擇流程**
```
用戶點擊地圖 → handleLocationSelect → 更新 selectedLocation → 顯示座標資訊 → 提交時包含座標
```

### 2. **手動輸入流程**
```
用戶輸入地址 → 更新 formData.address → 提交時使用地址 → 後端進行地理編碼
```

### 3. **統一提交邏輯**
```tsx
const submitData = {
  ...formData,
  address: finalAddress,
  latitude: selectedLocation?.lat,
  longitude: selectedLocation?.lng,
};
```
